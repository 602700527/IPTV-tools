## ADDED Requirements

### Requirement: CF Pages Configuration

The system SHALL provide configuration files for deploying the generated static site to Cloudflare Pages.

#### Scenario: Wrangler Pages config exists
- **WHEN** deploying to Cloudflare Pages
- **THEN** a `wrangler-pages.toml` file SHALL exist with project name and D1 database bindings

#### Scenario: GitHub Actions workflow for Pages
- **WHEN** code is pushed to main branch
- **THEN** a GitHub Actions workflow SHALL trigger `wrangler pages deploy` with the static output directory

### Requirement: CF Pages routing

The deployed Cloudflare Pages site SHALL route API and dynamic requests back to the Cloudflare Workers instance.

#### Scenario: Proxy API requests to Workers
- **WHEN** a request arrives at `/api/*` on Pages
- **THEN** Pages SHALL proxy the request to the configured Workers endpoint (e.g., `https://api.iptv-search.com/api/*`)

#### Scenario: Proxy playback requests to Workers
- **WHEN** a request arrives at `/live/*` on Pages
- **THEN** Pages SHALL proxy the request to the Workers `/live/*` endpoint

#### Scenario: Proxy subscription requests to Workers
- **WHEN** a request arrives at `/sub/*` on Pages
- **THEN** Pages SHALL proxy the request to the Workers `/sub/*` endpoint

### Requirement: Static file deployment

The static HTML files generated by the site generator SHALL be deployed to Cloudflare Pages.

#### Scenario: Deploy homepage to Pages
- **WHEN** the deployment workflow runs
- **THEN** the `index.html` SHALL be deployed to the Pages project root

#### Scenario: Deploy category pages to Pages
- **WHEN** the deployment workflow runs
- **THEN** all category HTML files SHALL be deployed to the `/category/` path in Pages

#### Scenario: Deploy channel pages to Pages
- **WHEN** the deployment workflow runs
- **THEN** all channel HTML files SHALL be deployed to the `/channel/` path in Pages

### Requirement: Pages environment variables

The Cloudflare Pages deployment SHALL have access to necessary environment variables for proper operation.

#### Scenario: APP_URL configured
- **WHEN** Pages serves a static page
- **THEN** the `APP_URL` environment variable SHALL be set to the Pages domain (e.g., `https://iptv-search.pages.dev`)

#### Scenario: Workers endpoint configured
- **WHEN** Pages proxies requests to Workers
- **THEN** the `WORKERS_URL` environment variable SHALL point to the Workers endpoint (e.g., `https://iptv-search.workers.dev`)
