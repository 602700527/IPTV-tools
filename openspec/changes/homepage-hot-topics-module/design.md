## Context

首页当前结构为：Header（Logo + 搜索框 + 导航）→ 频道分类区 → Footer。需要新增「热门专题」栏目在搜索框下方、频道分类区上方，作为页面过渡区域，同时承担内容发现和内部链接功能。

## Goals / Non-Goals

**Goals:**
- 创建视觉突出但不喧宾夺主的专题卡片模块
- 5个卡片均匀分布，响应式适配（桌面5列，移动端2-3列）
- 卡片风格与现有首页一致（深色卡片 + Netflix红强调色）
- 每个卡片可点击跳转至对应SEO落地页
- 保持首页加载性能，卡片数量少不影响首屏速度

**Non-Goals:**
- 不改变首页整体布局结构
- 不修改header、footer或其他现有组件
- 不添加复杂的动画效果（保持简洁）
- 不做A/B测试（基础版本一次到位）

## Decisions

### 决策 1: 栏目位置

**选择**: 搜索框下方，频道分类区上方

**原因**:
- 用户搜索后发现相关内容，增加停留可能性
- 不影响现有频道浏览动线
- 符合用户阅读习惯（先看专题入口，再浏览全量频道）

### 决策 2: 卡片布局

**选择**: 横向5列等宽布局（桌面），2列布局（平板），单列（手机）

**原因**:
- 5个专题刚好占满一行，视觉整齐
- 移动端2列或单列保证可读性
- CSS Grid 可实现简洁响应式

### 决策 3: 卡片内容

每个卡片包含：
- **图标**: 国旗emoji或主题图标（🇺🇸🇬🇧📺🤖🎬）
- **标题**: 专题名称（如"USA IPTV"）
- **副标题**: 简短描述（如"美国直播频道大全"）

**原因**:
- 图标增强视觉识别度
- 简洁文字让移动端也能完整显示

### 决策 4: 链接方式

**选择**: 直接 `<a>` 链接到落地页 URL

**原因**:
- 简单直接，SEO友好
- 不需要额外的 JS 交互逻辑

## Risks / Trade-offs

- **[权衡] 栏目优先级** - 搜索框下方位置宝贵，放专题可能影响频道曝光 → 后续可根据数据调整位置
- **[风险] 卡片风格与现有组件一致性** → 使用现有 CSS 变量（--accent, --bg-card 等）

## Migration Plan

1. 修改 `pages/home-page.js` 添加卡片 HTML
2. 添加必要 CSS 样式（可复用现有变量）
3. 本地测试 `npm run dev` 验证显示效果
4. 验证移动端响应式布局
5. 部署 `npm run deploy`

**Rollback**: git revert 修改即可回滚
