# Player Frontend Spec

## Overview

播放器的用户界面设计规范，包含UI组件和交互逻辑。

## Layout Structure

```
┌─────────────────────────────────────┐
│           页面最大宽度               │
│  ┌───────────────────────────────┐  │
│  │  [← 返回]      播放器标题     │  │  ← 顶部导航栏
│  ├───────────────────────────────┤  │
│  │                               │  │
│  │         视频播放区域           │  │
│  │       (16:9 有限宽度)         │  │
│  │                               │  │
│  ├───────────────────────────────┤  │
│  │  ▶️  ━━━━●━━━━━━  00:00/00:00⛶│  │  ← 控制条
│  └───────────────────────────────┘  │
└─────────────────────────────────────┘
```

### 布局参数
- 页面最大宽度：**600px**（移动端）/ **800px**（桌面端）
- 页面居中显示，水平方向居中
- 播放器宽度：100%但不超过最大宽度
- 播放器圆角：8px
- 播放器背景：深色（#1a1a2e）与页面背景形成对比

## UI Components

### 1. 顶部导航栏
- 返回按钮：左对齐，点击返回来源页面
- 标题：居中，固定显示"**正在播放**"
- 背景：半透明黑色渐变

### 2. 视频播放区
- 16:9比例容器
- 点击播放/暂停
- 双击全屏
- Loading遮罩：播放前显示圆形loading动画

### 3. 控制条
- 播放/暂停按钮
- 进度条：可拖拽定位
- 当前时间 / 总时长
- 全屏按钮
- 音量控制（hover显示）

### 4. 状态提示
- 加载中：中心loading动画
- 错误：红色提示框 + 重试按钮
- 空状态：不适用（播放器不主动显示）

## Interactions

### 播放控制
- 点击视频区域：播放/暂停切换
- 点击控制条播放按钮：播放/暂停
- 拖拽进度条：跳转播放位置
- 点击全屏：进入/退出全屏

### 返回操作
- 点击返回按钮：window.location.href = return参数

### 手势支持
- 移动端滑动进度条
- 移动端双击全屏

## Responsive Breakpoints
- Desktop: > 768px → 最大宽度 **800px**
- Mobile: ≤ 768px → 最大宽度 **600px**

### Desktop适配
- 播放器居中显示，两侧留白
- 控制条完整显示所有控件
- 鼠标悬停显示音量滑块

### Mobile适配
- 播放器最大宽度600px，居中
- 控制条简化：只保留播放/暂停、进度条、全屏
- 大触摸目标（44x44px最小）
- 防止页面滚动影响播放

### 画中画（PiP）支持
- 控制条添加PiP按钮（📺图标）
- 点击切换画中画模式
- 支持浏览器原生PiP API
- PiP模式下视频继续播放，用户可浏览其他页面
