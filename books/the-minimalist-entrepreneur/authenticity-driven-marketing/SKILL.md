# 真实性驱动营销 (Authenticity-Driven Marketing)

## R — 原文 (Reading)

> Marketing is just sharing what you're doing with people who care. The trick is to be yourself, share the journey, and let the right people find you. If you're trying to please everyone, you'll please no one. If you're trying to sell to everyone, you'll sell to no one.
>
> — Sahil Lavingia, *The Minimalist Entrepreneur*, Chapter 5: Market by Being You

---

## I — 方法论骨架 (Interpretation)

把营销从"花钱让陌生人看见"重新定义为"让自己活成内容,让对的人主动找来"。三个核心机制:

**1. 1% 法则 + 创造者阶梯**——任何受众群里 1% 是创造者、9% 是贡献者、90% 是潜水者。你不需要讨好 90%,而要服务好那 1% 创造者(他们会替你传播);你起步时要先成为 9% 贡献者(每天在别人的频道答问题、贡献内容),然后升级为 1% 创造者(发原创教程、开源工具、深度观点)。存在感按 10x→90x 跃迁。

**2. Educate/Inspire/Entertain 三级阶梯**——内容按受众规模指数级分三层:Level 1 教(目标受众就是你的客户,先小后稳)、Level 2 激励(讲从 0 到 1 的挣扎、价值观、个人故事,触达想活更好的人)、Level 3 娱乐(用幽默/段子的高传播性触达所有人)。人在少时犯错、人多时别冒险——先在 Level 1 站稳再升 Level 2,只有万级以上受众才考虑 Level 3。

**3. 邮件列表 = 自有地,社媒 = 租来的地**——平台随时改算法、封号、限流。一有粉丝就用 lead magnet 换邮箱,把关系建立在你直接触达的管道上。发布在社媒,关系在邮件。这是"别在租来的地上盖房"的硬规则。

该方法论反"广告+盛大发布+粉丝经济"三位一体;它的 ROI 模型是时间投入而非金钱投放,适合耐心、能持续输出、把自己活成产品一部分的极简创业者。

## A1 — 书中的应用 (Past Application)

### 案例 1: Adam Wathan & Steve Schoger / Refactoring UI
- **问题**: 两位前端工程师,想为 Tailwind CSS 开源框架贡献更好的设计示例,但当时没人教设计师写代码、没人教开发者做设计,中间是空白。
- **方法论的使用**: 先在 Twitter/博客上免费发"前端 UI 重构前后对比"(Educate),从 0 粉丝起步日更,几年沉淀成 Refactoring UI 社群。受众稳定后把内容做成 $39-$199 课程(Refactoring UI),赚 $800k。再用课程现金流反哺 Tailwind CSS 开源框架开发。
- **结论**: 免费内容 → 受众 → 课程 → 反哺开源的"三层叠加"是真实性营销的标准路径。
- **结果**: Refactoring UI 成为前端设计师事实教材;Tailwind CSS 成为最流行的 utility-first CSS 框架之一。

### 案例 2: Jenny Doan / Missouri Star Quilt Co
- **问题**: 密苏里州 Hamilton(人口 1500)小镇缝纫机店老板 Jenny Doan,2008 年经济危机时店铺几近破产。
- **方法论的使用**: 51 岁的 Jenny 真人出镜拍 YouTube 教程——10 个免费拼布教程,目标受众是和她一样的中年家庭主妇。她是社区成员、她用社区语言、她教学她最擅长的东西(Educate Level 1),从未请网红也未投广告。
- **结论**: 一个最小的真人内容输出,撬动百万订单的生意。
- **结果**: 频道订阅从 0 涨到 50 万+,Hamilton 镇变 "Quilt Disney",月销拼布材料百万美元,4 年后盈利才扩张。

### 案例 3: Brandon Sanderson 创意写作班
- **问题**: 作者 Sahil 在 Gumroad 估值暴跌后陷入身份危机,远离旧金山搬到 Provo。
- **方法论的使用**: 报名 Brandon Sanderson 的 BYU 创意写作硕士班,让自己回到"创造者"身份而非"创业者"身份。在这个真实社区里,Sahil 重新学会为自己创造而非为投资人/市场创造。
- **结论**: 真实性营销的前提是"你本人就是一个创造者";如果你不在任何社区里、不创造任何东西、不为自己做内容,营销就是空话。
- **结果**: Sahil 找回创作初心,Gumroad 后续的产品决策、文化叙事、Twitter 风格全部转向"分享我在做什么"。

### 案例 4: Jelani Memory / A Kids Book About
- **问题**: 六个孩子的父亲(其中 4 个白人、2 个棕色),找不到适合跟孩子谈种族话题的书。
- **方法论的使用**: 不做市场调研、不问"市场需要什么",直接为自己孩子写一本 A Kids Book About Racism。从自家真实处境出发(Educate Level 1),把"为自己家庭解决问题"作为内容的真实来源。
- **结论**: 最强内容永远来自"你自己正在解决的问题",而不是"市场报告里说的问题"。
- **结果**: 单本变成出版品类("A Kids Book About" 系列),被 Costco/Target 上架,作者成为 K-12 教育领域有影响力的声音。

### 案例 5: Adam Wathan 的"一条推文"招聘
- **问题**: 公司招前端工程师,传统招聘渠道(JD + LinkedIn)来的简历都不对路。
- **方法论的使用**: Adam 发了一条"opinionated tweet"——公开写自己公司用什么不用什么、薪资透明、对候选人的具体期望、哪些人请勿投。把招聘启事当成"真实性内容"的一部分。
- **结论**: 营销和招聘是同一件事——表达"你是谁、你坚持什么",让对的人主动出现,错的人主动离开。
- **结果**: 一条推文带来 875 份申请,其中相当比例是高匹配度候选人。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **准备花钱投放广告前**:用户说"我准备投 5000 块信息流/Google Ads/小红书种草"——应停下来问:你的内容管道(社媒 + 邮件)准备好了吗?不准备好就是烧钱。
2. **为产品上线/新功能筹备"盛大发布"时**:用户准备办 Product Hunt 启动、办线下 launch 活动、拍 demo video 砸预算——该建议把发布移到"已有 100 个付费客户 + 已有口碑"之后。
3. **不知道该写什么内容时**:用户问"我公众号/小红书/Newsletter 该更新什么"——该引导用户从自己的真实生活(创业过程、价值观、踩过的坑)出发,而不是追热点、抄竞品。
4. **"粉丝挺多但没人买"的困惑**:用户有几千几万社媒粉丝但转化率为 0——这是 audience ≠ customer 的典型症状,该建议聚焦 1% 创造者、收紧漏斗到付费转化。
5. **声称"我不会营销/我不是做内容的人"时**:用户在用"我不是营销人"为借口回避真实性表达——该提醒:真实性营销不是"营销技能",而是"你愿不愿意活成内容"。

### 语言信号 (用户的话里出现这些就应激活)

- "要不要投广告 / 找网红 / 买流量"
- "怎么搞个盛大发布 / launch event / Product Hunt 冲首页"
- "我不会做营销 / 我不是做内容的人"
- "公众号/小红书/Newsletter 不知道写什么"
- "粉丝不少但没人买 / 转化率这么低"
- "品牌曝光怎么做 / 怎么让大家知道我们"
- "B2B 获客要不要走抖音 / 小红书"

### 与相邻 skill 的区分

- **vs `right-size-business-sequencing` (序列纪律)**: 本 skill 是序列中的第 5 步 (Market by Being You) 的执行细节
- **vs `founder-led-sales-process` (创始人亲售)**: 销售是 out-bound 一对一,marketing 是 in-bound 一次触达多人。本 skill 前提是已经做完前者的 100 单, 知道"客户语言长什么样", 然后把它们放大
- **vs `mindful-growth-vc-or-bootstrap` (有节制成长)**: 有节制成长讲"何时/该不该花钱买流量" ; 本 skill 是"不花钱获取注意力的方法论"
- **vs (付费广告 / 增长黑客 / Performance Marketing)**: 本 skill 直接对立 — 反对用钱买注意力, 强调用真实性换信任

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **诊断现状(花时间买认知)**
   - 完成标准: 用户能回答三个问题——(a) 我的目标客户具体是谁、他们活跃在哪个社区/平台?(b) 我目前的内容管道(社媒 + 邮件)状态如何?(c) 我有没有一笔钱准备好投广告?——如果不是 100% 确定全部三个,继续 step 2。

2. **建立"1% 创造者"定位**
   - 完成标准: 用户能写出"我是 [某个具体社区] 里的 [解决某类问题] 的 [具体身份]——我能帮那 1% 创造者 [具体价值]"。例如"我是独立设计师社区里教设计师写代码的工程师,我帮前端开发设计师找到写 HTML/CSS 的最快路径"。如果定位模糊,跳到 step 2.5(贡献者起步)。

3. **选第一级(Educate)作为内容入口**
   - 完成标准: 用户能列出 10 个"我能教给目标客户的具体技能/知识/方法",且每条都是自己每天在做、自己有体感的(不是"市场研究说客户想知道")。
   - 判停条件: 若用户说"我不知道该教什么",回 step 1 重新做"创始人=首个用户"自检——大概率用户没在自己社区里、或没在用自己产品。

4. **建邮件列表(自有地)**
   - 完成标准: 用户已选好邮件平台(ConvertKit/Substack/Beehiiv 等),已设计一个 lead magnet(免费模板/电子书/工具),并制定"每次成交/每次内容发布都收集邮箱"的具体触发条件。
   - 判停条件: 若用户说"现在粉丝不多建邮件太早"——直接驳回:这正是从一开始就要做的,延迟成本是日后所有用户都流失到平台上的沉没成本。

5. **稳定输出节奏(不要追爆款)**
   - 完成标准: 用户承诺一个可持续的内容节奏(如每周 1 篇深度文章 + 每周 3 条社媒),并能坚持 3 个月不跳级。Level 1(Educate)站稳前不升 Level 2(Inspire)。

6. **(可选)Level 2/Level 3 进阶**
   - 完成标准: 当 Educate 内容已稳定带来 100+ 真实付费客户(注意是 customer 不是 follower)、邮件列表 1000+ 后,再考虑加 Inspire(个人故事/价值观)维度;只有受众 10,000+ 后才考虑 Entertain(幽默/段子)。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **已经有付费复购客户、想扩量**——转 `paid-ads-timing`(投放时机),那是付费广告的正确阶段,不要回头再"做内容"。
- **明确需要 cold outreach / cold email 找陌生人**——那是 `founder-led-sales` 范畴,真实性营销不解决主动陌生触达。
- **B2B 大客户销售周期长、内容营销看不到短期 ROI**——这种情况下该用 ABM/销售主导,真实性营销的 3-12 月复利周期不匹配。
- **产品本身没解决真问题**——真实性营销放大器,不是产品拯救器。如果客户访谈都过不了(见 `mvp-validation`),先回去修产品。

### 作者在书中警告的失败模式

- **ce09 — 追求"盛大发布"而非"先卖给 100 个人"** (Quibi $1.8B 失败): 把 launch 当终点仪式而非庆祝里程碑。
- **ce10 — 用钱而不是用时间买增长**: 停止投放的当周新增用户立刻跌 80%,CAC > LTV。
- **ce13 — 用 ad 之外的"增长黑客"找客户**: SEO/投放技巧再多,产品不行也是漏斗上端浪费。
- **ce17 — 把"寒暄/支持"等同于"潜在付费用户"**: 1 万粉丝不等于 100 个付费客户。
- **ce18 — 只做创始人账户,不做公司账户**: 人设账号才有"故事/脆弱性",公司账号没人看。
- **ce20 — 把品牌营销等同于广告**: 大公司"重复曝光"逻辑对小公司既不可负担也不必要。
- **ce25 — 把创业等同于身份**: 一旦业务出问题,身份受威胁,大脑启动保护机制而非理性调整,营销动力崩塌。

### 作者的盲点 / 时代局限

- **平台变迁风险**:Sahil 写书时(2019-2021)重点在 Twitter/Instagram/YouTube;今天抖音/小红书/B 站的算法逻辑更激进,邮件 lead magnet 的转化率可能更低,用户需要结合当下平台特性调整"自有地"的定义(可能包含私域社群、视频号、小报童等)。
- **人格化营销的天花板**:Sahil 假设创始人本人有故事可讲;但对一些 B2B 后端工具、数据基础设施类产品的创始人,"真实性"难以包装成故事,这种 skill 适用度有限。
- **1% 法则的现代版本**:今天算法推荐弱化了"潜水者自然下沉"的机制,创造者的曝光更多被算法劫持;在 TikTok/Reels 上,即使 1% 创造者也未必能自然浮出水面,需要接受"为算法而写"的妥协。

### 容易混淆的邻近方法论

- **个人品牌 ≠ 真实性营销**: 个人品牌常常滑向"打造一个完美形象",真实性营销要求"暴露正在学习的自己"。
- **内容营销 ≠ Educate/Inspire/Entertain**: 传统内容营销聚焦 SEO 漏斗;这里的三级阶梯是按受众规模分,目标是"人少时练手,人多时别冒险",而非关键词排名。
- **Build in Public ≠ Market by Being You**: Build in Public 是过程(公开进度),Market by Being You 是结果(因为你是你所以客户找你);前者是手段,后者是目的。
