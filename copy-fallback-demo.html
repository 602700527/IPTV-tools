点击按钮模拟复制播放链接。切换下方开关可模拟 Clipboard API 被浏览器阻止的情况。

// 实际实现逻辑
async function copyToClipboardWithFallback(text) {
  if (navigator.clipboard && navigator.clipboard.writeText) {
    try {
      await navigator.clipboard.writeText(text);
      showToast('Link copied!');
      return;
    } catch (err) { console.log('Clipboard failed'); }
    }
  fallbackCopy(text);
}
✅ 成功 - Modern Clipboard API
链接已复制到剪贴板！可以直接粘贴到 IPTV 播放器中使用。
🔄 降级方案 1 - Selection + execCommand
Clipboard API 被拒绝（可能未授权）。自动切换到 Selection API + textarea 方案进行复制。
🔄 降级方案 2 - Range API
Selection API 也失败了。使用 Range API 直接选中页面元素内容进行复制。
📝 最终方案 - 显示链接文本
所有自动复制方案均失败。直接显示链接内容，长按或手动选择复制。

🧩 降级方案详解 Technical Details

三种降级方案层层递进，确保任何环境下都能获取到链接

方案 1: Selection API + execCommand

创建隐藏的 textarea，设置固定定位到视口外，设置 opacity 为 0，尺寸为 1x1 像素。将文本写入后通过 focus() 激活，使用 select() 选中内容，最后调用 execCommand('copy') 复制。

方案 2: Range API

创建 div 元素，将文本内容放入。使用 document.createRange() 创建范围，selectNodeContents() 选择元素内容，通过 window.getSelection() 操作选择，最后执行复制命令。

方案 3: 显示链接文本

所有自动复制方式均失败后，直接在 Toast 中显示链接内容（截断到80字符），用户可以长按选择复制或手动输入。
