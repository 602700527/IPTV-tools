# Checklist

## 验收检查点

### 传统SEO结构化数据验收

- [ ] 首页JSON-LD包含WebSite类型，符合Schema.org规范
- [ ] 首页JSON-LD包含SearchAction搜索动作配置
- [ ] 首页JSON-LD包含FAQPage类型，至少10个问题答案对
- [ ] 分类页JSON-LD包含BreadcrumbList类型
- [ ] 分类页面包屑路径：首页 > 分类名称
- [ ] 频道页JSON-LD包含VideoObject类型
- [ ] 频道页VideoObject包含name、description、thumbnailUrl

### GEO（生成式引擎优化）验收

- [ ] 首页包含Organization结构化数据类型
- [ ] Organization包含：name、description、url、logo、sameAs（社交媒体）
- [ ] FAQ答案详细，包含用户可能询问的各种问题
- [ ] FAQ覆盖主题：免费观看、订阅优势、支持设备、频道数量、合法性等

### FAQ营销区块验收（页脚共享）

- [ ] 页脚组件包含FAQ区块
- [ ] FAQ区块包含至少10个问题
- [ ] 点击问题可展开/收起答案
- [ ] FAQ样式在深色/浅色模式下正常显示
- [ ] 首页底部显示FAQ区块
- [ ] 分类页底部显示FAQ区块
- [ ] 频道页底部显示FAQ区块
- [ ] 所有页面共享同一FAQ区块

### 功能验收

- [ ] 页面加载性能无明显影响
- [ ] 主导航功能正常
- [ ] 主题切换功能正常
- [ ] 翻译功能正常

### SEO验证（使用工具）

- [ ] Google Rich Results Test - 首页通过
- [ ] Google Rich Results Test - 分类页通过
- [ ] Google Rich Results Test - 频道页通过
